# Project-Management-Dashboard

To run the project, run index.html file with Live server
**NOTE : ** please don't open directly from fileFolder because fileFolder don't run the script file, So please open with live server

**NOTE :** to add more than one employee user **CONTROL OR SHIFT** key in mac then click on that employee in project's Action column

Core Features (Must Have):
1. Add Project - Fields: Project Name, Deadline, Priority (Low/Medium/High) : DONE
2. Add Employee - Fields: Name, Role (e.g., Developer, Manager)             : DONE
3. Assign Employee to Project - Allow assigning one or more employees to a project  : DONE
4. List View - Display all projects in a table or card view. Show: Name, Deadline, Priority, Assigned Employees : DONE
5. Delete a project or an employee : DONE
6. Mark a project as completed (status) : DONE
7. Filter projects by priority/status : DONE
8. Save data in localStorage (simulate backend persistence) : DONE (on reload , data persist)
9. Export Excel report of project list - must include list of projects, assigned team, status, : DONE
10. Show a dashboard summary (e.g., total projects, completed projects) : DONE (showing at the top)

Bonus for Extra Credit
Responsive UI with basic styling : DONE
